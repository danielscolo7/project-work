# Gold Thief Project

- **s346508.py**: defines the required `solution(problem)` wrapper, which extracts parameters from the `Problem` instance and calls `goldThief` to return the optimized path as a list of `(city, gold)` tuples ending with `(0, 0)`.

- **goldThief.py**: implements the main heuristic algorithm, using a greedy incremental approach with adaptive route merging and controlled randomization. It iteratively combines trips only when it reduces the total cost, respecting limits based on problem parameters `alpha` and `beta`.

- **src/runTest.py**: script to test `solution(problem)` on multiple problem instances and compare it with a baseline, printing results and saving them in a spreadsheet.

- **src/results.xlsx**: output file generated by `runTest.py` containing the costs for baseline and `goldThief`, along with improvement percentages.

For further explanations, see the project report.
