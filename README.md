# Gold Thief Project

This repository contains the code for the Gold Thief project.

- `Problem.py`: defines the problem class, generates the graph, and provides the baseline solution.
- `s346508.py`: implements the main algorithm (`goldThief(problem)`), returning the optimized path as a list of `(city, gold)` tuples ending with `(0, 0)`.
- `src/runTest.py`: script to test the solution on multiple problem instances and compare it with the baseline.
- `src/results.xlsx`: output file generated by `runTest.py` containing costs and improvement percentages.
- `base_requirements.txt`: lists the Python libraries required to run the project.

See the report for detailed explanation of the algorithm, data structures, and experimental results.
