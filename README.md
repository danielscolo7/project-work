# Gold Thief Project

- **s346508.py**: defines the required `solution(problem)` wrapper, which extracts parameters from the `Problem` instance and calls `goldThief` to return the optimized path as a list of `(city, gold)` tuples ending with `(0, 0)`.

- **goldThief.py**: implements the main heuristic algorithm, using a greedy incremental approach with adaptive route merging and controlled randomization.
The algorithm:
merges trips only when it strictly reduces the total cost, respects limits based on problem parameters alpha and beta, includes explicit validity checks on the generated path, ensuring:
no two consecutive identical cities, no transitions between non-adjacent cities (only existing graph edges are allowed), no invalid consecutive depot visits (e.g., (0, 0) followed by (0, 0)), final path always ends correctly at (0, 0).

- **src/runTest.py**: script to test solution(problem) on multiple problem instances and compare it with a baseline.
To execute all tests and generate the results file, run:
python src/runTest.py

The script prints the comparison in the terminal and automatically generates the results spreadsheet.

- **src/results.xlsx**: output file generated by `runTest.py` containing the costs for baseline and `goldThief`, along with improvement percentages.
